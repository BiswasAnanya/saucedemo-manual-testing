# BUG-004: Inventory Layout Inconsistencies for `visual_user`

**Status:** Open

**Severity:** Low

**Priority:** P3

**Related Test-Case:** TC-109

**Related Test-Suite:** Product Inventory

## Description

The Inventory page contains visual and layout inconsistencies when using `visual_user`, including issues with product images, spacing, alignment, or overall presentation.

## Preconditions

* Browser is open on the SauceDemo Login page.

## Steps to Reproduce

1. Log in with `visual_user` / `secret_sauce`.
2. Navigate to the Inventory page.
3. Review the product images, spacing, alignment, and overall page layout.

## Expected Result

The Inventory page should maintain the expected layout, spacing, alignment, and visual presentation.

## Actual Result

Visual and UI inconsistencies are present on the Inventory page for `visual_user`.

![Bug evidence](../Screenshots/bug-004.png)

## Notes

This is primarily a visual/UI defect and does not prevent the user from continuing through the core shopping flow.
